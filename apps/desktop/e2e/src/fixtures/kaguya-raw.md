# 《超时空辉夜姬》剧情大纲

在近未来的东京，独自生活的女高中生酒寄彩叶在一个深夜从发光的电线杆中捡到了一个婴儿，婴儿三天内成长为自称来自月球的少女"辉夜"，两人由此开始了鸡飞狗跳的同居生活。辉夜拉着彩叶以"辉夜·彩P"组合参加虚拟空间"月读"中的歌姬竞赛"八千代杯"，彩叶在辉夜的推动下重新拾起因父亲去世和母亲否定而封存多年的钢琴，两人一路逆袭夺冠，并与虚拟歌姬"月见八千代"成功举办了合作演唱会。然而演唱会后，来自月球的"月人"入侵，辉夜被迫在满月之夜回到月球，彩叶在悲痛中终于与母亲和解、放弃"完美女高中生"的伪装，选择追寻自己真正想走的路。此后彩叶发现了一个跨越八千年的真相：辉夜回到月球后因思念彩叶而穿越时空，却意外坠落在八千年前的地球，失去肉体的她以海蛞蝓之躯孤独地度过了八千年，最终在互联网时代创造了"月读"、以"八千代"的身份歌唱，只为等待与彩叶重逢--而彩叶幼时听到的那首《Remember》，正是辉夜在八千年间唯一唱过的歌。十年后，成为研究者的彩叶终于完成了辉夜的虚拟躯体，在所有人的见证下，准备迎接辉夜的"第一个生日"，将这场跨越八千年的重逢画上真正的句号。
